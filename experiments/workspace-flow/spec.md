# Load Workspace experiment

One physical composition on near-black navy. A cyan packet sits on the browser socket. Four glass instruments name Browser, API, Authorization, and PostgreSQL. Thin channels show the outbound route and a dashed response route. Cyan appears at the next handoff and mint marks the delivered response. A heading and a single explanatory readout sit outside the routing surface.

| Moment | What happens |
|---|---|
| Pointer down | The token takes pointer capture and compresses slightly. The API socket illuminates to show the destination. |
| Drag | The token follows a damped spring toward the pointer. Inside the API capture radius, attraction pulls the token toward the socket and the socket ring strengthens. |
| Release | The release position and a short projection of recent pointer velocity determine capture. Moving toward the API near its socket can complete a flick. A miss or cancellation springs back to the browser. A tap or keyboard activation launches from the browser. |
| Node activation | The packet first docks at the API, then reaches authorization. Session verification and tenant scoping register as separate beats at that socket. PostgreSQL illuminates when the scoped query arrives. The API shapes the returned data before the response travels to the browser. Each arrival changes the explanation. |
| Completion | The browser receives the response, the token settles at its origin in mint, and the readout explains the dashboard update. |
| Reset | Reset cancels the current motion and releases pointer capture. The token and explanation return to Ready. |

On narrow displays the layout folds into a two-by-two route with the same sequence. Launch and Reset are native buttons. With reduced motion, drag follows the pointer directly, and playback advances between stationary states with enough dwell to read each explanation. The experiment uses an isolated SaaS graph fixture with authentication and tenancy enabled. It runs from a standalone Vite development entry.
